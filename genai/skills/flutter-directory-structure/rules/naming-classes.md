## Class Naming

| 種類 | 例 |
|------|-----|
| Repository | `AuthRepository`, `TodoRepository` |
| Controller（AsyncNotifier） | `LoginController`, `RegisterController` |
| Screen | `LoginScreen` |
| Model | `Todo`, `CreateTodoRequest`（`*Model` / Entity 分離なしで可） |
