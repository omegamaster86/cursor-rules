## Widget Colocation

```
presentation/login/
├── login_screen.dart
├── login_controller.dart
└── widgets/
    └── login_form.dart
```

`presentation/screens/[画面]/widgets/` 形式は必須ではない。画面名ディレクトリ + `widgets/` でよい。
