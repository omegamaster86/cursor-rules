## Component Testing with React Testing Library

**ステータス（dev-starter）:** `frontend/web` には **React Testing Library / Vitest は未導入**。必要になったときのオプション。

導入する場合は Vitest + `@testing-library/react` をセットで追加し、ユーザー操作に近いクエリ（`getByRole` 等）を優先する。
