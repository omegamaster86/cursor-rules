# 型と命名

## 概要

TypeScript の型定義と命名をプロジェクト規約に合わせて統一する。

## 必須参照

型や命名を変更する前に `references/rules-map.md` を読む。

## 型定義ワークフロー

1. 既存の型/スキーマを確認し、再利用できるか判断する。
2. 型・関数・ファイルの命名規約に従う。
3. `any` を避け、必要に応じて `database.types.ts` を使う。
4. スキーマ型は中央集約（例: `src/types/schemas.ts`）を維持する。

## 最終チェック

- 命名が規約と一致しているか確認する。
- 型定義の export と利用箇所の整合を確認する。
