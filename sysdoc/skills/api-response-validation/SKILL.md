# API レスポンス検証

## 概要
API レスポンスを規約に従って検証し、整合性を保つ。

## 必須参照
API レスポンススキーマ変更前に `references/rules-map.md` を読む。

## 検証ワークフロー
1. 変更対象のエンドポイント/Server Action を特定する。
2. `src/types/schemas.ts` の既存スキーマを確認する。
3. 規約に従ってスキーマを更新/追加する。
4. 返却前にレスポンス形状を検証する。

## 最終チェック
- サーバー/クライアントでスキーマの利用が一致しているか確認する。
- レスポンス形状が安定し、スキーマに記載されているか確認する。
