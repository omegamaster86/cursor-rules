# 原則で舵を取る

23 本は `forge-mode/principles/` に leaf がある。forge-mode 起動時はインデックスを読み、タスクに該当するものだけ全文読む。

チャットで原則名を出すと agent が該当 leaf を開きやすい。

| よく使う名前 | いつ |
|-------------|------|
| laziness-protocol | 抽象・層を足したくなったとき |
| foundational-thinking | ロジックの前にデータ形状 |
| fix-root-causes | nil-check で黙らせない |
| prove-it-works | 完了前（手順は `/verify-done`） |
| never-block-on-the-human | 可逆作業の実行分岐（Align 済みの Ship のみ） |
| separate-before-serializing-shared-state | 並行が同じファイルを書く前 |

一覧: [skills/README.md](../../skills/README.md) の原則表。
