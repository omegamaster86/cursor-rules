# 理解する

編集前に構造と経緯を分ける。

| スキル | 聞くこと |
|--------|----------|
| `/how` | どう動くか、どこにあるか、データの流れ |
| `/why` | なぜこう作ったか（MCP 並列で証拠） |
| `/recall` | 過去チャットから同トピックの現状 brief |

読み取り専用の質問は forge-mode の **Investigation** プレイブックにマッチします。

```text
/forge-mode このキャンセル API は冪等？呼び出し元を全部洗いたい。
```
