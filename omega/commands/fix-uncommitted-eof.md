# 未コミットファイルの EOF 空行を直す

未コミットのテキストファイルに **EOF の不要な空行**（最終行の後に改行が2つ以上）があれば直す。正しい末尾は `.cursor/rules/file-eof.mdc` と同じく **最後の意味ある行の直後に改行1つだけ**。不要なら何もしない。

## 手順（エージェント）

1. 未コミット一覧（未ステージ・ステージ済み・未追跡）を対象に、末尾が規約どおりか確認する。
2. 問題があるファイルだけ正規化する。まず次を **1 回** 実行してよい（`git` が見えるディレクトリからで可。スクリプト側でリポジトリルートに移る）。

```bash
bash .cursor/scripts/fix-uncommitted-eof.sh
```

3. スクリプトが使えない・対象が一部だけのときは、同じ規約で `StrReplace` / 書き込みで **未コミットファイルのみ** 末尾を直す（本題のコードは変えない）。
4. 修正したファイル名を短く報告する。末尾が空行だけの `git diff` が残っていないことを確認する。
5. **コミットはユーザーが依頼したときだけ**。

## 対象

- `git diff`・`git diff --cached`・`git ls-files --others --exclude-standard` の和集合
- 一般的なテキスト（`.ts`, `.tsx`, `.md`, `.json` など）。バイナリ・UTF-8 以外はスキップ

## 注意

- `.cursor/` は gitignore のためチーム clone には載らない（ローカル運用）。
- `omega-sync` 再実行で `.cursor/commands` が symlink に戻ったら、本コマンドを再配置する。
