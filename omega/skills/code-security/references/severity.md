# 重大度・信頼度（共通）

## Severity

| 値 | 基準 |
|----|------|
| critical | 即時に重大な侵害（RCE、全面データ漏洩、認可完全突破） |
| high | 現実的な高影響・高可能性の経路 |
| medium | 高影響だが前提が重い、または中影響で可能性が高い |
| low | 影響が限定的、または前提が非現実的 |

自己のみ・同一テナント内・localhost 限定など、境界を越えない問題は下げる。デプロイ未確認は**信頼度**を下げ、finding 自体を消す理由にはしない。

## Confidence（検証）

| 値 | 意味 |
|----|------|
| verified | 独立 verifier パネルで 2/3 以上が「本物の脆弱性」と判断 |
| provisional | 研究者のみ。パネル未実施または票割れ |
| rejected | パネルが反証付きで却下（レポートに載せない。coverage に記録可） |

## ソースに埋め込まれた秘密

「ソースを読める主体が、その読み取り以上の権限を持つ credential を得る」経路は有効。実行経路やユーザー入力は不要。ダミー・公開鍵・プレースホルダは区別する。秘密の**実利用や外部送信はしない**。
