# Create a formal verification skill

テストは誰かが書いたケースを見る。形式的検証は宣言した範囲の**すべて**を見る：モデル上のすべての手順順序、境界までのすべての入力、またはすべての入力。このスキルは repo でそれが最も効く箇所を見つけ、1 性質を検証し、次のエージェントが変更をその性質に照らせる project-local スキルを残す。スキルは cold・mid-change で読む次のエージェント向けに書く。ユーザーは検証言語を学ばずに結果を信じ、行動できること。

## コードからターゲットを選ぶ

codebase から答え、観察できないことだけユーザーに聞く。ユーザーが領域やバグを名指したらそこから。

良いターゲットは、破れたときユーザーに害があり、破れケースにテストがほとんど届かない**約束**。検証が楽なものではなく、最も強い約束を選ぶ。

## 問いがツールを選ぶ

モデルチェッカ、証明支援、SMT 検証器など、最小コストで答えるツールを選ぶ。悪い順序が起きうるかは小さな設計モデルへのモデルチェックが向き、言語問わず TLA+ が既定。コード自体の全入力振る舞い（メモリ安全、オーバーフロー、データ構造 invariant）はコード上の検証器が向く。この言語に検証器が無ければそう言い、手モデルではなく実コードへの生成入力でテストする。サイズ無制限で成り立つ性質は証明が要る場合がある。開発者が install・実行できるツールを優先し、選んだ理由を述べる。

## 良い検証の条件

- **コードに忠実。** モデル・証明の各部分が reviewer が開けるコードを指す。検証が 1 不可分割ステップとみなすものは、コードでも 1 ステップ。名前はこの repo から。
- **失敗できる。** 一度も失敗を見ていないチェックは何も証明しない。守る性質が、チェック削除や順序入れ替えなどの壊れた variant で失敗することを示す。
- **発見は発見のまま。** 現コードが性質を破るなら、反例をコードの言葉で報告する。通るまで性質やモデルを弱めない。ユーザーが求めない限りプロダクトコードは変えない。
- **範囲を正直に。** 何を、どの境界・仮定の下で検証し、何を外すか。pass はモデルまたは境界の pass であり、システム全体ではない。
- **ツール無しで読める。** 性質と害を各 1 平易文。反例はコードの言葉での短い手順列。
- **再実行が安い。** 1 コマンド、再現可能なツール版、次のエージェントが relevant 変更ごとに走らせる長さ。
- **コードと同期。** 各チェックがカバーする file・関数と、検証がコードを描写したと最後に確認した commit を記録。カバー後にコードが変わったら、次のエージェントが検証の見直しが要ると分かる。

## verify スキルを生成

領域と使用タイミングを frontmatter に書く project-local スキル。frontmatter 無しでは登録されない。スキルだけで、変更が検証コードに触れるか、チェックを走らせ、実バグとモデリング誤りを分け、意図した変更時に検証を更新できること。カバー記録と sync commit をスキルに置き、新 commit で描写を確認したときだけ sync commit を進めるよう次のエージェントに書く。placeholder を残さない。

チェックが TLA+ なら、次のエージェントに [`/statechart`](../statechart/SKILL.md) で結果を読むよう書く。invariant 違反ごとに最短パスを平易語で示し、変更がどれを直すか分かる。pass 時は状態遷移のチャートを描く。`/statechart` は名前で参照する。コマンド・オプション・パスはリリースや環境で変わるので、生成スキルやその script にコピーしない。

## 渡す前に証明

生成スキルを次のエージェントと同様に 1 回走らせ、性質を実コードで破す scratch 変更で試す。破れを捕まえること。scratch を戻し、報告する発見だけ失敗するか pass に戻ることを確認。一度も走っていない verify スキルは draft。破れを逃したら scratch ではなくスキルまたは検証を直す。

## 引き渡し

何を検証したか、ツールと理由、境界、平易語での結果、実行方法、カバー外を述べる。近い第 2 ターゲットは見つかったときだけ提案。検証を再チェックしなかった変更後の同期は [`/maintain-formal-verification-skill`](../maintain-formal-verification-skill/SKILL.md) を指す。
