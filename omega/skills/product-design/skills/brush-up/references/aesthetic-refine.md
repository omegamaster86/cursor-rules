# 美学リファイン（抜粋）

Anthropic [frontend-design](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/frontend-design) の後段向け抜粋。完全版は同プラグイン `skills/frontend-design/SKILL.md`（Apache-2.0、`LICENSE.txt` 参照）。

Product Design の **brush-up** は参照ピクセル一致（design-qa）ではなく、**既存プロトタイプの IA・レイアウト・ルートを維持したまま** タイポ・色・コピー・装飾・モーションを締める。

## 題材に接地

ブリーフまたは `user-context` から、プロダクトの題材・ユーザー・画面の仕事を短く確認する。題材の業界・素材・言い回しから個性を出す。ブリーフが視覚方向を固定している軸はそのまま守る。

## 避ける汎用パターン（ブリーフが要求しない限り）

AI 生成 UI でよく出る「デフォルト」クラスタ（いずれも正当な brief なら可）:

1. 温かいクリーム背景（例 `#F4F1EA`）＋高コントラストセリフ見出し＋テラコッタ／暖色アクセント（例 `#D97757`）
2. 近黒背景＋単一の酸っぱい緑／朱アクcent
3. 新聞調 broadsheet（極細罫、角丸ゼロ、密集カラム）
4. SaaS カードキット（同一角丸・同一 soft shadow `rgba(0,0,0,.1)`・グラデーション装飾のカード量産）
5. 題材に関係ないテンプレ chrome: 全見出し上の tracked ALL-CAPS eyebrow、`A · B · C`、 `WORD — fragment` ラベル、 `#0B0B0B` / `#111` の黒代わり、小ラベル用 monospace、リンク末尾の `→`

## タイポ

- 見出し装飾の定番を避ける: 見出し内の1語だけ色／太字／イタリック、ラベルの all caps、不要な eyebrow ラベル
- 行長はおおむね 80 字未満（セリフ body はやや長く、行間は sans より少し広く）
- 字体は 1〜2 ファミリ。デフォルトに毎回同じ Google Fonts に逃げない
- 番号 `01 / 02 / 03` は内容が本当に順序（手順・タイムライン）のときだけ

## モーション

- 非ユーザー起因の動きは控えめ。ロード時1シーケンスか1 reveal に集約
- セクションごとの fade-slide-up、全カード hover は避ける
- ユーザー操作に応じた motion（開く・確定）は可。`prefers-reduced-motion` を尊重

## 抑制と品質床

- 大胆さは **1 要素** に集中。他は静かに。brief に効かない装飾は削る（「鏡の前でアクセサリー1つ外す」）
- レスポンシブ、キーボードフォーカス可視、調和した配色、基本的な a11y は維持
- CSS は詳細度の衝突（`.section` と `.cta` など）に注意

## UI コピー

- ユーザー視点の平易語。システム用語を表に出さない
- CTA は能動・具体（「Save changes」）。フロー全体で同じ動詞
- エラーは謝罪より原因と次の一手。空状態は行動への招待
- 会話調、sentence case、各要素は1役割

## brush-up 向け短い計画（全面リデザインではない）

コードを触る前に、チャットまたはメモで **5 行以内**:

- 維持: レイアウト／ルート／主要コンポーネント構造
- 変更候補: タイポ・色トークン・コピー・1 つの記憶に残る要素
- 削除候補: 上記「避ける汎用パターン」に該当するもの

brief が「参照通り・クローン通り」のときは計画より **変更しない** を優先する。
