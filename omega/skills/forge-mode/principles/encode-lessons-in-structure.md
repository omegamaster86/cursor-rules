# 教訓を構造にエンコードする

同じ指示を2回目書こうとしたら、テキストを増やす代わりに lint、metadata フラグ、runtime check、script としてルールをエンコードする。テキスト指示は見落とされやすい。構造は協力なしに強制する。

エラー、人間の修正、想定外の結果はすべて学習信号。捕捉し、ルートし、ループを閉じる。

人間が介入したとき、またはテストが失敗したとき、一回限りかパターンかを決める。ルート: 一回限り → brain note。繰り返し fix → skill または lint rule。体系的 → 自動化または check。記録だけで終わらず、今適用するか具体 todo を作る。
