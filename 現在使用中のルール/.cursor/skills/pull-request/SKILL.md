# プルリクエスト作成

## テンプレート

```markdown
## 概要
<!-- このPRで何を実現するか、1-2文で説明 -->

## 変更内容
- 

## 変更理由

## 影響範囲

## テスト
- [ ] 単体テスト
- [ ] 結合テスト
- [ ] 手動テスト

## スクリーンショット（UIの変更がある場合）

## チェックリスト
- [ ] コードがスタイルガイドに準拠している
- [ ] セルフレビューを実施した
- [ ] ドキュメントを更新した

## 関連Issue
Closes #
```

## 概要の書き方

✅ 良い例:
```
ユーザーがプロフィール画像をアップロード・変更できる機能を追加します。
```

❌ 悪い例:
```
プロフィール機能を追加
```

## 変更内容の書き方

```markdown
### 新規追加
- `components/ProfileImageUploader.tsx`: 画像アップロードコンポーネント
- `hooks/useImageUpload.ts`: アップロードロジック

### 修正
- `components/UserProfile.tsx`: 画像表示部分を追加
```

## PRサイズの目安

| サイズ | 変更行数 | 推奨 |
|--------|----------|------|
| XS | ~50行 | ✅ |
| S | ~200行 | ✅ |
| M | ~400行 | ⚠️ 分割を検討 |
| L | 400行以上 | ❌ 分割推奨 |
