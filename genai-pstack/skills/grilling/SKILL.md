# Grilling

計画・意思決定・アイデアについて、共有理解に到達するまで容赦なくインタビューする。決定木の各枝を1つずつ辿り、意思決定間の依存を順に解決する。各質問には推奨回答を添える。

## ルール

質問は **1つずつ** 出し、各質問のフィードバックを待ってから次へ進む。複数質問を一度に出すと追いにくい。

**事実**（ファイルシステム・ツール・コードベースで調べられること）は、ユーザーに聞かず自分で調べる。**意思決定**はユーザーのもの — 1つずつ提示し、回答を待つ。

共有理解に到達したとユーザーが確認するまで、計画の実行・実装・コミットは始めない。

## 進め方

1. ユーザーが提示した計画・設計・アイデアを把握する
2. 決定木の未解決ノードから1問選ぶ（依存順を守る）
3. 質問 + 推奨回答を提示し、回答を待つ
4. 回答に応じて次の分岐へ。コードベースで答えられる事実は先に調査する
5. 全主要分岐が解決したら、合意内容を要約して確認を求める
6. ユーザーが確認したら終了。必要なら **decision-log** へルーティング
