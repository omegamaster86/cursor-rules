# ビルド修正

TypeScriptとビルドエラーを段階的に修正する:

1. ビルド実行: npm run build または pnpm build

2. エラー出力を解析:
   - ファイルごとにグルーピング
   - 重大度でソート

3. 各エラーについて:
   - エラーコンテキスト表示（前後5行）
   - 問題を説明
   - 修正案を提示
   - 修正を適用
   - 再ビルド
   - 解決確認

4. 次の場合は停止:
   - 修正が新しいエラーを生む
   - 同じエラーが3回以上継続
   - ユーザーが一時停止を依頼

5. サマリ表示:
   - 修正済みエラー
   - 残エラー
   - 新規エラー

安全のため、1回に1件ずつ修正すること!
