# ドキュメント更新

ソース・オブ・トゥルースからドキュメントを同期する:

1. package.json の scripts セクションを読む
   - スクリプト参照表を生成
   - コメントから説明を含める

2. .env.example を読む
   - すべての環境変数を抽出
   - 目的と形式を記載

3. docs/CONTRIB.md を生成:
   - 開発ワークフロー
   - 利用可能なスクリプト
   - 環境設定
   - テスト手順

4. docs/RUNBOOK.md を生成:
   - デプロイ手順
   - 監視とアラート
   - よくある問題と対処
   - ロールバック手順

5. 古いドキュメントを特定:
   - 90日以上更新されていないdocsを抽出
   - 手動レビュー用に一覧化

6. 差分サマリを表示

単一の正: package.json と .env.example
