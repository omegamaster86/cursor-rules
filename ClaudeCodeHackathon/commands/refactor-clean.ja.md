# リファクタクリーン

テスト検証を行いながら、安全にデッドコードを特定・削除する:

1. デッドコード解析ツールを実行:
   - knip: 未使用のエクスポート/ファイルを検出
   - depcheck: 未使用依存を検出
   - ts-prune: 未使用TypeScriptエクスポートを検出

2. `.reports/dead-code-analysis.md` に包括的レポートを生成

3. 重大度で分類:
   - SAFE: テストファイル、未使用ユーティリティ
   - CAUTION: APIルート、コンポーネント
   - DANGER: 設定ファイル、メインエントリ

4. 安全な削除のみ提案

5. 各削除の前に:
   - 全テスト実行
   - テスト通過確認
   - 変更適用
   - 再度テスト
   - 失敗時はロールバック

6. クリーン対象の要約を表示

テストなしで削除してはいけない!
