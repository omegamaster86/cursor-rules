# コマンド: Zenn記事を新規作成する

以下の入力を基に、`記事作成/zenn-article.mdc` のルールに準拠した Zenn 記事の雛形を生成してください。

## 入力（開発者が与える）
- テーマ/トピック（必須）: 例) Next.js の並行ルーティング入門
- 角度（必須）: 入門/実践/落とし穴/設計指針/比較 など
- 想定読者（任意）: 例) React の基本が分かる初中級者
- 前提（任意）: 例) Node.js 18+, pnpm, プロジェクト初期化済み
- 到達目標（任意）: 読了後に具体的にできること
- 文字量の目安（任意）: 例) 約1500–2500字
- Zenn type（任意）: `tech` | `idea`（未指定は `tech`）
- Zenn topics（任意）: 1–5個の英小文字スラグ

不足があれば、最小限の質問を1ターンだけ行い、それでも不足する場合は妥当な仮定を置いて進めてください（仮定は明示）。

## 出力要件
1. フロントマター（YAML）を最上部に出力
2. 続けて本文の骨子と最初のドラフト（H2/H3で構成）
3. 文体は「です・ます調」。用語は初出で補足。
4. コードブロックは言語指定を付与（例: ```ts, ```bash）
5. まとめ/参考リンクを必ず含める

## 生成フォーマット（厳守）

```
---
title: "<生成したタイトル>"
emoji: "<適切な絵文字>"
type: "<tech|idea>"
topics: [<topic1>, <topic2>]
published: false
---

<リード（2–4行）>

## 想定読者 / 前提
- ...

## 到達目標
- ...

## <H2: 章タイトル>
### <H3: 節タイトル>
...（問題→背景→手順/コード→解説→注意点）

## まとめ
- 要点1
- 要点2
- 次アクション

## 参考
- 公式: <URL>
```
