# PR コメント取得

## トリガー

対象 PR のフィードバックを簡潔で実行可能な形に要約する必要がある場合。

## ワークフロー

1. 現在のブランチに紐づく PR を解決。
2. レビューコメントと議論コメントを取得。
3. フィードバックを重要度と実行可能性でグループ化。
4. 優先度付きで簡潔なアクションリストを返す。

## 出力

- 重要度別のフィードバック要約
- 優先度順のアクションリスト
- 追加確認が必要な未解決質問
