# AI コードのスラップ除去

main と差分を比較し、ブランチで導入された AI 由来の不要変更を除去します。

## 注視ポイント

- ローカルスタイルと整合性が取れていない不要なコメント
- 信頼できる経路で異常な防御的チェックや try/catch
- 型問題を回避するだけの `any` キャスト
- 深いネストを early return で平坦化できる箇所
- ファイルと周辺コードベースに不自然なパターン

## ガードレール

- 明確なバグ修正以外で振る舞いを変えない。
- 大規模改修より、最小・焦点を絞った編集を優先。
- 最終サマリは簡潔に（1〜3 文）。
