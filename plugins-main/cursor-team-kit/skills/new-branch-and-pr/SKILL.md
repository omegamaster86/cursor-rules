# New branch and PR

## トリガー

クリーンなブランチと PR ワークフローで出荷する作業を開始するとき。

## ワークフロー

1. 作業ツリーがクリーンであること、または意図的に対処済みであることを確認。
2. 最新の main から説明的な名前のブランチを作成。
3. 実装とテストを完了。
4. 焦点を絞った変更をコミットし push。
5. 概要とテストノートを含む簡潔な PR を作成。

## ガードレール

- ブランチ範囲は 1 つの変更セットに集中。
- レビュー依頼前に検証ノートを含める。

## 出力

- 新規ブランチ名
- PR 概要とテストノート
- PR URL
